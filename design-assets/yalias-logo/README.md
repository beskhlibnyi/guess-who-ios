# YALIAS logo assets

These are approved design masters only. They are not referenced by the Xcode project or the live asset catalog.

- `yalias-app-icon-1024.png`: opaque 1024 × 1024 candidate for the iOS app icon.
- `yalias-app-icon-master-1254.png`: original opaque generated master.
- `yalias-start-screen-logo-1024.png`: 1024 × 1024 transparent start-screen logo.
- `yalias-start-screen-logo-master-1254.png`: original transparent generated master.

Palette:

- Mustard: `#F2B51D`
- Vermilion: `#D94A32`
- Warm cream: `#F9ECD9`
- Paper: `#FFF3DE`
- Ink: `#211E19`

The app icon is intentionally square and opaque; iOS applies the corner mask at runtime.
